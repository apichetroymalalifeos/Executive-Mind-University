# Product First Principles

## 1. ผู้ใช้ต้องการเปลี่ยนแปลงอะไรในชีวิตจริง

ผู้ใช้ต้องการเปลี่ยนจากการเรียนเพื่อรู้ เป็นการฝึกคิด ตัดสินใจ ลงมือทำ และทบทวนผลจริงในชีวิตประจำวัน โดยเฉพาะบริบท Sales, AI Business, Health, Investing, Family และ Leadership

## 2. อุปสรรคพื้นฐานที่ทำให้คนเรียนมากแต่ไม่เปลี่ยนพฤติกรรม

- ความรู้ไม่ถูกแปลงเป็น action ภายในเวลาสั้นพอ
- ไม่มีระบบทบทวนผลจริง จึงไม่เห็น feedback loop
- แยก Fact, Assumption, Opinion และ Uncertainty ไม่ชัด
- บทเรียนไม่ผูกกับ decision ที่ผู้ใช้กำลังเผชิญ
- แบบฝึกหัดใหญ่เกินไปจนเริ่มยาก
- ใช้ outcome ตัดสิน decision แทนที่จะดู process quality

## 3. ฟีเจอร์ที่จำเป็นต่อผลลัพธ์หลัก

- Daily recommendation แบบ rule-based
- Lesson progress และ review interval
- Daily exercise และ Action Contract
- Decision Journal พร้อม prediction, confidence และ actual outcome
- Reflection ที่แปลงผลลัพธ์เป็น weak areas
- Local persistence, export/import, migration และ backup
- Content freshness และ human-reviewed update workflow

## 4. ฟีเจอร์ที่ยังเป็นความซับซ้อนที่ไม่จำเป็น

- AI API, cloud sync, login, social features, leaderboard
- Automatic knowledge publishing without human review
- Large content marketplace
- Gamification ที่ไม่ได้ช่วย Applied Decisions
- Advanced analytics ก่อนมีข้อมูลจริง

## 5. เราจะรู้ได้อย่างไรว่าผู้ใช้คิดและตัดสินใจดีขึ้น

North Star Metric คือจำนวน Applied Decisions ที่ผู้ใช้ลงมือทำและกลับมาทบทวนผลจริง

สัญญาณสนับสนุน:

- Decision review rate สูงขึ้น
- Prediction accuracy ดีขึ้นตามช่วง confidence
- Weak areas ลดลงจาก quiz, reflection และ decision patterns
- Action completion rate และ exercise completion rate สูงขึ้น
- ผู้ใช้แยก fact, assumption, opinion และ unknown ได้สม่ำเสมอขึ้น

## 6. สมมติฐานที่ต้องทดสอบ

- ผู้ใช้ยอมบันทึก decision ก่อนตัดสินใจจริง
- บทเรียนสั้น 20-30 นาทีพอเปลี่ยนพฤติกรรมได้เมื่อมี action ภายใน 24 ชั่วโมง
- Rule-based recommendation เพียงพอใน MVP
- Audio mode ช่วยให้เรียนระหว่างเดินทางได้โดยไม่เพิ่มความเสี่ยง
- Knowledge freshness ที่โปร่งใสสร้าง trust มากกว่าเนื้อหาเยอะ

## 7. วิธีที่ง่ายที่สุดในการพิสูจน์คุณค่า

สร้าง loop เดียวให้จบ: วันนี้เลือกบทเรียนหนึ่งบท สร้าง exercise หนึ่งข้อ บันทึก decision หนึ่งรายการ ลงมือหนึ่ง action และกลับมาทบทวนผลจริงในวันนัด review
