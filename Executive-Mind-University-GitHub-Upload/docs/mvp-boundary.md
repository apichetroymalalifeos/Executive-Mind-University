# MVP Boundary

## Included in Phase 1

- App shell and required routes
- Domain interfaces for seven engines
- Service layer for seven engines
- Versioned storage envelope
- Safe storage reads and writes
- Validation, migration, backup and rollback primitives
- Import/export preview and dry-run primitives
- Unit tests and route smoke tests
- Documentation for privacy, migration, and manual acceptance checks

## Excluded Until Later Phases

- Full Lesson 1 content
- Audio mode
- Decision Journal UI
- Knowledge Center UI
- Future Readiness dashboard
- Complete import merge UI
- Full accessibility QA
- Bundle optimization beyond baseline reporting
- Any backend, login, cloud sync, paid API, or automatic content update
